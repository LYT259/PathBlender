# 2026.9.6 — 双通道更新三视角审查：发现并修复 beta 通道三处断裂

用户要求对「双通道自动更新」（Mac/Windows/Linux × stable/beta）做三件事：边界情况审计并补测试、以陌生评审视角过代码、推演上线后最可能的严重 Bug。审计结论：**beta 通道从未端到端工作过**，三处独立断裂叠加，其中任何一处都足以让通道语义失效。全部修复 + 29 条新测试。

## 发现的断裂（按严重度）

1. **应用内：通道 feed 覆盖是无效代码**。`check({ url: channelFeedUrl(...) } as never)` —— 插件 JS `check()` 的 `CheckOptions` 没有 `url` 字段，`{...options}` 透传到 Rust 后被 serde 静默丢弃，端点永远来自 tauri.conf.json（stable）。所谓「beta 回退检查」实际是把 stable 端点原样再查一遍；`as never` 强转恰好掩住了类型层的报警。beta 用户永远拿不到 beta feed。
2. **CI：prerelease 判定是死代码 + beta tag 会污染 stable feed**。release.yml 在「Create GitHub Release」**之前**用 `gh api releases/tags/...` 查 prerelease —— 此时 release 尚不存在，404 → `|| echo false`，判定恒为 false；`gh release create` 又从不带 `--prerelease`。后果：latest-beta.json 永远不会生成；beta tag 会成为正式 release 并抢占 GitHub "latest"，stable 用户的 latest.json 直接指向 beta 构建（**stable 用户收到 beta 更新**——本次审查对「最严重 Bug」的答案）。
3. **次级问题**：错误语义不诚实（离线/404 与「已是最新」都报 upToDate，与代码注释宣称的 fallback 文案相反）；桌面 ⌘, 偏好窗口切通道不触发检查（与功能描述「切通道即查即下」不符）；gen-latest-json 以 `writeFileSync('latest-beta.json')` 往 cwd 副作用写文件；AISettings 里残留 `updateChannel` 死字段（与真正的通道存储双源）；tauri.conf.json/gen-latest-json 仓库大小写与实际仓库名不一致（GitHub 重定向兜底，纯一致性）。

## 修复

- **通道→feed 白名单移入 Rust 壳**（`check_update(channel)` / `install_update` 命令，lib.rs）：`updater_builder().endpoints(...)` 运行时选 feed；`Ok(None)`=已最新、`Err`=feed 不可达，语义诚实。Update 存 `Mutex<Option<Update>>`，锁用块作用域收尾保 future Send（显式 drop 过不了生成器分析）。
- **新增 `update-check.ts` runner**（纯 TS，可测）：事件流 found/upToDate/installed/failed；relaunch 失败当 best-effort（Windows 安装器自行退出应用）。App.tsx 消费事件映射 i18n toast；新增 `updates.failed` 键（三语，zh-tw 由 gen-zh-hant 重生成），删除无人消费的 `updates.none`。
- **任一窗口切通道即检查**：App 订阅 `listenPrefs('updateChannel')`（pref 事件自送达），事件携带新值直接传给 runner，无 stale closure；偏好弹窗里的内联调用删除（消除双查）。web 端 listenPrefs 为 no-op，行为不变。
- **CI 渠道路由重写**：新 `scripts/release-channel.mjs`（tag 后缀 -alpha/-beta/-rc → beta，纯函数可测）；stable tag 发布 latest.json + latest-beta.json 双 feed（stable 会抬升 beta 通道），beta tag 只发 latest-beta.json 且 `gh release create --prerelease`（GitHub latest 语义双保险，stable 永不见 beta）；删除死掉的 gh api 查询。gen-latest-json 只写 stdout（副作用文件删除），beta 注释后缀仅由版本号自身的预发布后缀驱动。
- 清理：AISettings.updateChannel 死字段、web 侧不再使用的 @tauri-apps/plugin-updater JS 依赖（Rust crate 保留）、端点统一小写仓库名。
