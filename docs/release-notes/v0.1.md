**PathBlender v0.1** — first public release.

A zero-install, zero-upload web tool for FRC alliance strategy groups: blend
every partner team's autonomous path exports onto one field, replay them on a
shared 15-second clock, and check for collisions before they happen in a match.

## Features

- **Multi-toolchain import**: Choreo `.traj` (all known schema versions),
  PathPlanner `.path` / `.auto` (trajectory generation runs in your browser —
  a TypeScript port of PathPlannerLib), and Collaborative fork `.ghostauto`
  (carries bumper geometry and team names)
- **Unified timeline playback**: play / pause / scrub, 0.25×–4× speed,
  per-robot color bands with conflict (red) and out-of-bounds (orange) segments
- **Collision & interference checking**: bumper-rectangle OBB-SAT overlap
  across the whole timeline (0.02 s sampling), conflict report with jump-to-
  moment, minimum-separation report, field-bounds (out-of-bounds) detection
- **What-if start delays**: offset any robot without touching its file
- **Red/blue alliance normalization** per robot (WPILib transform semantics)
- **Fields**: 2022–2026 seasons built in; custom field import with two-point
  calibration and AprilTag layouts (WPILib/PhotonVision JSON)
- **Sharing**: session files (`.ghpb.json`), share links (whole session in the
  URL hash — no server), PNG export
- **Mediation editing & export**: drag / insert / remove waypoints with live
  collision recompute; derived copies (`-adjusted`) with reset-to-original;
  export back to `.path` / `.traj` / `.ghostauto`
- **Optional AI assistant** (off by default): bring your own
  OpenAI-compatible endpoint (Zhipu Z.ai / OpenAI / DeepSeek / Ollama); acts only
  through a whitelisted, undoable command set; exports/removals require
  confirmation; keys never leave the browser
- **Team-number annotations** drawn on every robot (carried by `.ghostauto`,
  editable per card)
- **PWA**: installable, works offline (static assets cached)
- **Languages**: English / 简体中文 / 繁體中文

## Known limitations

- `.path` / `.auto` trajectories are generated with a default robot
  configuration (mass, motors, gearing) since those files carry none — timing
  is an estimate (see the in-app warning). Collision geometry honors the
  editable per-robot size.
- Rare pre-2025 PathPlanner constraint types are not applied; affected paths
  import with an explicit warning.
- `.auto` parallel/race command groups are sequentialized (warned); named
  commands contribute zero time (warned).

## Privacy

Static web page, no backend, no accounts, no telemetry. Files are parsed in
your browser and never leave it. Share links contain only the compressed
session itself.
