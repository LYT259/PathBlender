# PathBlender 使用指南（策略组版）

给联盟策略组的赛前协调工具：把各队导出的自动路径文件放到同一场地上，统一时间轴回放，自动检查碰撞。**所有文件都在你的浏览器里解析，不会上传到任何地方。**

## 三步上手

1. **打开链接**（发布后的网址见 README；支持 Safari / Chrome / Edge），或启动桌面版 App。
2. **把文件拖进窗口**——支持多选混拖：Choreo 的 `.traj`、PathPlanner 的 `.path` / `.auto`、103 fork 的 `.ghostauto`。坏的文件会报错说明原因，不影响其他文件导入。
3. **按播放**。有碰撞风险的地方：场地上出现红色圆环、时间轴上出现红色区段、右侧冲突面板列出「谁和谁、什么时刻、在哪里」——点一条，时钟直接跳到那个瞬间。

## 各队怎么导出文件

| 队用的工具 | 导出什么 | 怎么导 |
|---|---|---|
| Choreo | `.traj` | Choreo 里导出轨迹（Export → traj） |
| PathPlanner | `.path` + `.auto` | 直接从项目目录拿文件；**`.auto` 引用的每个 `.path` 要一起拖进来**（同一次拖入即可） |
| 装了 103 Collaborative fork 的队 | `.ghostauto` | fork 里导出 ghost，自带机器人尺寸和队名 |

## 消解冲突的三条路

1. **一键消解**：冲突面板顶部「一键消解」——自动寻找让所有冲突消失的**最小起步延迟组合**（0.25 秒步进，偏向让先出发的一方让行）。个别「同路径重复录入」式冲突无法用延迟解决时，会如实提示剩余数量，交给你人工判断。
2. **手动起步延迟（what-if）**：机器人卡片上的 delay 输入框，给一台加 1~3 秒，冲突面板实时刷新。延迟只在当前会话，**不改任何原文件**。
3. **路径编辑**（见下节）：时间错不开就改几何。

## 路径编辑（画布内）

在机器人详情面板点**编辑路径**（`.path` / `.traj` 支持；`.ghostauto` 无路点数据），画布切入编辑模式：其余机器人与碰撞检查照常运行，

- 场地上**拖动路点**；**双击**线段插入、**右键**删除；
- 右侧**路点面板**精确编辑数值：PathPlanner 行可展开锚点与前/后控制点坐标，Choreo 行直接改 x/y（朝向只读）；
- 每次改动即时重算轨迹与碰撞——红环消失即达成调解。改动的是**派生副本**（机器人带「已调整」徽标，可一键撤销全部）；
- 详情面板直接导出 **.path / .traj / .ghostauto**（文件名带 `-adjusted` 后缀），发回给对方队伍在原工具里打开。PathPlanner 路径会重新生成时间轴，Choreo 路径保留原时间分布仅重映射几何（有警告标注）。

## 3D 视图与场地

- 顶部 **3D** 按钮切换到立体视图：**2022–2026 使用官方场地 3D 模型**（含 2025 焊接场/AndyMark 场两种结构，2026 同理可切换标签布局），自由环绕视角；「适配」按当前内容自适应取景，默认机位按钮一键回位。
- 2D 视图为快速战术叠加层，带各赛季官方 AprilTag 布局；2018–2020 无官方 3D 模型，3D 下使用简化结构。
- 赛季选择旁的 **Welded / AndyMark** 下拉仅在有两种场地结构的赛季出现——按你们赛场的实际结构选，标签位置随之对齐。

## 其他常用功能

- **红蓝联盟**：对方以红方视角画的路径，在机器人卡片上点 Red 切换归属，系统自动镜像到统一坐标系；
- **赛季与自定义场地**：顶栏切换 2018–2026 赛季；也能导入自定义场地图片（标定 + AprilTag 布局 JSON）；
- **分享**：菜单「分享…」把整个会话压进网址（纯前端，无服务器）；「保存会话」存 `.ghpb.json` 发群；「导出 PNG」直接出图；桌面版在 PathBlender 菜单里；
- **外观与语言**：偏好设置里深色/浅色/跟随系统，简体中文 / 繁體中文 / English；桌面版 ⌘, 打开偏好；
- **装成 App**（网页版）：Safari「添加到 Dock」/ Chrome「安装」；桌面版直接下载 dmg 安装，应用内可检查更新。

## 常见问题

**Q：导 `.path` 时提示「generated with default robot config — timing is an estimate」？**
`.path` 文件只存路点，轨迹是本工具在浏览器里重新生成的，用的是通用机器人参数（质量/电机）。时间轴是接近值（通常误差在几百毫秒级），碰撞检查结论供参考；对时间敏感的协调建议双方都核对一遍。

**Q：导 `.auto` 报「routine references path "xxx" — import the matching .path file too」？**
`.auto` 是例程（引用多条路径 + 等待/命令），把对应的 `.path` 文件和它**同一批**拖入即可。

**Q：回合制里说的是 15 秒自动期，时间轴更长/更短？**
时间轴长度 = 所有轨迹（含延迟）的最长者。每台机器人的色带如实显示自己的起止。

**Q：一键消解后仍有剩余冲突？**
剩余冲突多为「两台机器人整段路径重叠」这类延迟解不开的结构性冲突（比如同一条路径被录了两次）——检查是否有重复导入的路径，删掉一份再试。

**Q：数据安全吗？**
纯静态网页，零后端、零账号、零遥测——文件解析全在你的浏览器内存里完成，分享链接里的数据也只在你复制时才离开页面。

**Q：碰到不认识的文件/格式报错？**
把报错截图（或文件本身）发给发布帖——格式漂移报告正是我们需要的反馈。
