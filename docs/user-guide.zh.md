# PathBlender 使用指南（策略组版）

给联盟策略组的赛前协调工具：把各队导出的自动路径文件放到同一场地上，统一时间轴回放，自动检查碰撞。**所有文件都在你的浏览器里解析，不会上传到任何地方。**

## 三步上手

1. **打开链接**（发布后的网址见 README；支持 Safari / Chrome / Edge）。
2. **把文件拖进窗口**——支持多选混拖：Choreo 的 `.traj`、PathPlanner 的 `.path` / `.auto`、103 fork 的 `.ghostauto`。坏的文件会报错说明原因，不影响其他文件导入。
3. **按播放**。有碰撞风险的地方：场地上出现红色圆环、时间轴上出现红色区段、右侧冲突面板列出「谁和谁、什么时刻、在哪里」——点一条，时钟直接跳到那个瞬间。

## 各队怎么导出文件

| 队用的工具 | 导出什么 | 怎么导 |
|---|---|---|
| Choreo | `.traj` | Choreo 里导出轨迹（Export → traj） |
| PathPlanner | `.path` + `.auto` | 直接从项目目录拿文件；**`.auto` 引用的每个 `.path` 要一起拖进来**（同一次拖入即可） |
| 装了 103 Collaborative fork 的队 | `.ghostauto` | fork 里导出 ghost，自带机器人尺寸和队名 |

## 用「起步延迟」调解冲突（what-if）

发现两台机器人在 4~5 秒撞上？不要让谁重画路径——先试错开时间：

1. 在左侧机器人卡片上找到 **delay（延迟）** 输入框；
2. 给其中一台加 1~3 秒起步延迟；
3. 冲突面板实时刷新。冲突消失就说明「晚 X 秒出发」即可解决，把结论带给对方队即可。

延迟只存在于当前会话，**不会改动任何人的原文件**。同理可以临时改机器人长宽（几何编辑）让检查更贴近实车。

## 其他常用功能

- **红蓝联盟**：对方以红方视角画的路径，在机器人卡片上点 Red 切换归属，系统自动镜像到统一坐标系；
- **赛季场地**：右上角切换 2022–2026 赛季；也能导入自定义场地图片（两点标定 + AprilTag 布局 JSON）；
- **分享**：右上角 Share link 把整个会话压进网址（纯前端，无服务器）；或 Save session 存成 `.ghpb.json` 文件发群；或直接导出 PNG 截图；
- **三语**：顶栏切换 简体中文 / 繁體中文 / English；
- **装成 App**：Safari「添加到 Dock」/ Chrome「安装」——独立窗口 + 图标，赛场断网也能打开（静态资源已缓存）。

## 调解编辑与导出（v1.4 新增）

发现冲突后除了调延迟，还能直接微调路径几何：

1. 机器人卡片上点 **编辑路径**（仅 `.path` / `.traj` 支持；`.ghostauto` 无路点数据）；
2. 场地上**拖动白色路点**（PathPlanner 路径还有控制点，虚线臂连接）；**双击**线段插入新路点，**右键**路点删除；
3. 每次改动即时重算碰撞——红环消失就达成了调解。改动的是**派生副本**（卡片显示「已调整」，可一键**重置**回原样）；PathPlanner 路径会重新生成时间轴，Choreo 路径保留原时间分布仅重映射几何（卡片有警告标注）；
4. 点卡片上的 **.path / .traj / .ghostauto** 导出调整副本（文件名带 `-adjusted` 后缀），发回给对方队伍在原工具里打开使用。

## AI 助手（v1.4 新增，默认关闭）

顶栏 **AI** 按钮打开面板：填服务商（智谱 / OpenAI / DeepSeek / 本地 Ollama 或自定义）、接口地址、模型名和你的 API Key 后连接。之后可以用自然语言下指令，例如「把 2 号机延迟 0.5 秒避开碰撞，然后导出全部路径」。

纪律：密钥只存本浏览器，绝不进入会话文件/分享链接/导出物；AI 只能执行白名单命令（改延迟/联盟/队号/路点、查询冲突等），每个动作可撤销，**导出和删除机器人会先弹出确认**；碰撞结论永远来自确定性检测器而非 AI 判断。不想要了随时**断开**。启用期间路径数据会发送到你配置的服务商——配本地 Ollama 可做到数据不出本机。

## 常见问题

**Q：导 `.path` 时提示「generated with default robot config — timing is an estimate」？**
`.path` 文件只存路点，轨迹是本工具在浏览器里重新生成的，用的是通用机器人参数（质量/电机）。时间轴是接近值（通常误差在几百毫秒级），碰撞检查结论供参考；对时间敏感的协调建议双方都核对一遍。

**Q：导 `.auto` 报「routine references path "xxx" — import the matching .path file too」？**
`.auto` 是例程（引用多条路径 + 等待/命令），把对应的 `.path` 文件和它**同一批**拖入即可。

**Q：回合制里说的是 15 秒自动期，时间轴更长/更短？**
时间轴长度 = 所有轨迹（含延迟）的最长者。每台机器人的色带如实显示自己的起止。

**Q：数据安全吗？**
纯静态网页，零后端、零账号、零遥测——文件解析全在你的浏览器内存里完成，分享链接里的数据也只在你复制时才离开页面。

**Q：碰到不认识的文件/格式报错？**
把报错截图（或文件本身）发给发布帖——格式漂移报告正是我们需要的反馈。
