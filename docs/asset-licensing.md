# Asset licensing and provenance

PathBlender's own code uses [Apache-2.0](../LICENSE). The maintained asset-by-asset
attribution, evidence limits, reuse guidance, and rights-concern process are in
[NOTICE.md](../NOTICE.md), which is included in web and desktop distributions.
A repository-wide code license is not a blanket license for its third-party assets.

## MK5i evidence

- Direct source: FRCDesignLib's public Onshape Swerve document, V235, accessed
  through the FRC Designs ecosystem. FRCDesignApp is the insertion tool.
- Used assets: the module GLB and derived 2D top-view image. Frame assemblies
  are recorded separately as maintainer-built assets.
- Published MIT text: applies to the FRCDesignApp GitHub repository; retained
  at [licenses/FRCDesignApp-MIT.txt](../licenses/FRCDesignApp-MIT.txt).
- The maintainer's request explicitly described conversion and public distribution,
  including historical commits/tags: https://github.com/frcdesign/FRCDesignApp/issues/61#issuecomment-6033731974
- The supplied Discord screenshot displays 2026-10-09 and a direct reply by
  Alex Kempen. He expressed no objection to educational use while expressly
  leaving SDS/WCP licensing to those parties. Screenshot timezone is unverified.
- This is evidence supporting the project's interpretation of its described use;
  it is not a blanket MIT grant for the models, commercial-use clearance, or
  authorization from SDS/WCP. Each component's ultimate authorship is unverified.

The [CAD provenance record](../scripts/cad/README.md) retains the reply text,
export checksum, conversion process, and distinction from official reference CAD.
Keep full screenshots and correspondence privately; do not publish personal
information or imply that a transcription alone independently authenticates them.

## SDS written permission

SDS MK5i CAD-derived visualization assets are used and distributed with
PathBlender with express permission from Swerve Drive Specialties. This is a
project-specific written permission for the SDS MK5i portions of the module GLB
and derived 2D visualization, not an Apache-2.0, MIT, CC0, or other standard
open-source grant. It does not cover the Kraken X60 geometry or the
maintainer-built frame assemblies. FRCDesignLib and FRCDesignApp source
attribution is retained. Naming the assets "SDS MK5i" follows SDS's attribution
preference, not a license requirement, and does not imply sponsorship,
certification, or endorsement.

The reply was recorded from the maintainer's supplied authorization on
2026-10-31. Full correspondence and personal contact details remain private;
only the permission and its scope are published.

## Distributing and reusing assets

Follow each asset's actual terms and retain applicable notices. Do not describe
an unresolved permission as confirmed. Public availability does not itself
establish unrestricted redistribution rights. Older commits and packages retain
their own contents; a new document does not retroactively obtain permission.
For rights concerns, use the process in [NOTICE.md](../NOTICE.md), without posting
confidential evidence in a public issue.
